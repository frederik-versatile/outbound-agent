# ICP Criteria — Example

Copy this file to `<deployment_id>.md` and fill in with the customer's real
ideal-customer-profile. The prioritization_agent reads this doc and turns it
into Apollo organization-search filters, so be concrete rather than vague —
"B2B SaaS, 50-500 employees" scores better than "companies that need us."

## Industry
- Primary: e.g. B2B SaaS, vertical software
- Excluded: e.g. agencies, non-profits

## Company size
- Employee range: e.g. 50-500
- Revenue range (if known): e.g. $5M-$50M ARR

## Geography
- e.g. North America, UK, DACH

## Buying signals
- e.g. recently raised a funding round
- e.g. hiring for [specific role]
- e.g. using [specific technology] (Apollo technology filter)
- e.g. recent leadership change in [department]

## Disqualifiers
- e.g. already a customer
- e.g. fewer than N employees
- e.g. competitor
